# 무적문장 110

토익스피킹 IM1(110점) 목표 24시간 만능문장 암기 웹앱입니다. 휴대폰에 설치하면 오프라인에서도 열립니다.

## 휴대폰에 설치하기
- **iPhone (Safari)**: 주소를 열고 공유 버튼 → '홈 화면에 추가'
- **Android (Chrome)**: 주소를 열고 메뉴(⋮) → '앱 설치' 또는 '홈 화면에 추가'

외운 문장 체크와 플랜 진행은 그 기기에만 저장됩니다.

## 구성
- `index.html` 앱 전체 (문장 데이터 포함)
- `sw.js` 오프라인 캐시, `manifest.webmanifest` 설치 정보, `icons/` 앱 아이콘
- `fonts/` Pretendard 일부 글자만 담은 폰트 (SIL Open Font License 1.1, `fonts/Pretendard-LICENSE.txt`)
